# @videoia/design

Módulo de **Diseño Gráfico Programable** basado en el ecosistema de código abierto de **OpenPencil**.

## 📌 Capacidades
- **SceneGraph Vectorial:** Generación y manipulación de nodos, formas, textos, vectores y estilos vía código TypeScript.
- **Compatibilidad Figma (`.fig`) y OpenPencil (`.pen`):** Importación, parseo y exportación directa de archivos de diseño compatibles con Figma.
- **Motor de Renderizado:** Basado en CanvasKit (Skia WebAssembly) y Yoga Layout para cálculo preciso de flexbox y capas.
- **Automatización por IA:** Creación de banners, miniaturas de video, posts de redes y piezas gráficas mediante prompts.

## 🚀 Comandos

```bash
# Ejecutar entorno de diseño
pnpm run design:dev

# O desde esta carpeta
pnpm dev
```
